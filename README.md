# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

**日切口径（全局唯一）：强制作废未结。** 封口后切营业日时，旧日全部未结号（等候/叫号中/办理中/过号）
在同一事务内统一作废并逐条留审计；窗口当前号指针清空、号段游标归零、新日号段从 001 重发；
切日回执落库且可重放（同一原营业日重试返回同一回执）；任一步失败整笔回滚。旧日号牌切日后不可再办结。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`
